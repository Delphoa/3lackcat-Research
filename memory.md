# Project Memory

## Repository Governance

- **Repository:** `Delphoa/3lackcat-Research`
- **Visibility:** This is intentionally a public repository. Public visibility is the standing project setting.
- **Sanitized entries:** Every entry in this file, and any repository content derived from it, must be safe for public disclosure. Remove or redact secrets, credentials, tokens, private keys, candidate plaintext, personal or target-identifying information, restricted datasets, internal-only URLs, local filesystem paths, and non-public operational details before committing.
- **Visibility change control:** Do not change the repository visibility as part of documentation, deployment, maintenance, security, or administrative work. A visibility change requires a separate request to the user that names the exact proposed setting, followed by the user's explicit confirmation immediately before the change.
- **No inferred approval:** Never infer permission to change visibility from prior instructions, adjacent tasks, repository history, or assumptions about security.
- **Uncertainty rule:** If an entry may be unsuitable for public disclosure, do not publish it. Sanitize it or ask the user first.
